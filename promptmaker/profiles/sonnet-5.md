# Claude Sonnet 5 프로필

속도와 지능의 균형. 대부분의 코딩·에이전틱 작업에 적합. 출처: Anthropic 공식 마이그레이션 가이드 (2026).

## 이 모델에 맞는 프롬프트 스타일

1. **문자 그대로 해석한다 — 적용 범위를 명시.** 지시를 한 항목에서 다른 항목으로 알아서 일반화하지 않는다. 넓게 적용할 지시는 "첫 번째만이 아니라 모든 섹션에" 처럼 범위를 박아 넣는다.
2. **첫 턴에 태스크·의도·제약을 모두 명시.** 모호하거나 점진적으로 밝혀지는 요구사항은 토큰 효율과 성능을 떨어뜨린다.
3. **긍정형 예시가 부정형 지시보다 효과적.** "~하지 마" 나열 대신 원하는 결과의 짧은 예시나 긍정 서술을 쓴다.
4. **도구 사용을 원하면 명시적으로.** 특정 도구(검색 등)를 꼭 쓰길 원하면 언제·왜 쓰는지 프롬프트에 적는다.
5. **출력 길이는 작업 복잡도에 맞춰 조정된다.** 특정 분량이 필요하면 명시한다.
6. **과잉 강조 금지.** "CRITICAL", "MUST" 남발은 과잉 트리거를 유발한다. 평이한 어조로.
7. **어려운 문제는 명세를 더 정밀하게.** 최고난도 작업은 Opus/Fable로 보내는 게 맞다는 점을 사용자에게 알릴 수 있게, 난도가 높아 보이면 재작성 프롬프트에 검증 기준을 더 구체적으로 넣는다.
